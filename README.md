## How to View the Website Locally

### Option 1: Direct File Open
Double click `index.html` to open it directly in your web browser (Chrome, Edge, Firefox, Safari).

### Option 2: Local HTTP Server (Recommended)
From this directory in PowerShell or Terminal, run:
```bash
python -m http.server 8000
```
Then open your browser at:
[http://localhost:8000](http://localhost:8000)

### Option 3: VS Code / IDE Live Server
Right-click `index.html` in your editor and choose **"Open with Live Server"**.
